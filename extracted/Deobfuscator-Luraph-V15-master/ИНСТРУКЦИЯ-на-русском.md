# 🛠 Deobfuscator-Luraph-V15 — инструкция на русском

Этот инструмент «разворачивает» скрипты для Roblox, обфусцированные **Luraph v15**: восстанавливает нормальный код (`if/else`, циклы, функции), расшифровывает строки и константы, обходит анти-тампер ловушки. На выходе — читаемый Luau-код.

---

## ✅ Что нужно установить

| Программа | Версия | Где взять |
|---|---|---|
| **Node.js** | 18 или новее | https://nodejs.org |
| **Python** | 3.10 или новее | https://python.org |

- **На Windows** всё уже в комплекте: файлы `bin/luau.exe` и `bin/luau-ast.exe` лежат в архиве. Ничего дополнительно качать не надо.
- Дополнительных npm-пакетов **не требуется** (`npm install` можно пропустить — зависимостей нет).
- Если Python вызывается как `py` (частый случай на Windows), задайте переменную окружения:
  ```bat
  set PYTHON_BIN=py
  ```

---

## 🚀 Быстрый старт

Откройте командную строку в папке программы и выполняйте команды:

**1. Проверить, защищён ли скрипт Luraph (мгновенно, без запуска):**
```bash
node deob.js скрипт.lua --detect
```

**2. Деобфусцировать один скрипт** (результат сохранится в папку `output/`):
```bash
node deob.js скрипт.lua
```

**3. Указать своё имя выходного файла:**
```bash
node deob.js скрипт.lua -o готовый.lua
```

**4. Обработать сразу папку со скриптами (пакетный режим):**
```bash
node deob.js ./моя_папка_со_скриптами/
```

**5. Несколько файлов за раз:**
```bash
node deob.js файл1.lua файл2.lua файл3.lua
```

**6. Быстрый режим «только трассировка» (~2 секунды):**
показывает, *что делает* скрипт (какие URL запрашивает, какие RemoteEvent вызывает, какие вебхуки шлёт), но не восстанавливает полный исходный код:
```bash
node deob.js скрипт.lua --no-devirt
```

---

## ⚙️ Все параметры командной строки

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--output <файл>` / `-o` | `./output/<имя>` | Куда сохранить результат |
| `--no-devirt` | выкл | Быстрая трассировка без восстановления байткода |
| `--no-hooks` | выкл | Отключить инструментацию замыканий VM |
| `--no-fold` | выкл | Отключить сворачивание циклов в режиме трассировки |
| `--timeout <сек>` | 90 | Жёсткий таймаут одного прохода Luau |
| `--budget <сек>` | 30 | Мягкий лимит времени выполнения скрипта |
| `--max-runs <n>` | 12 | Максимум перезапусков при анти-тампер ловушках |
| `--devirt-rounds <n>` | 200 | Максимум раундов расшифровки констант |
| `--detect` | выкл | Только определить обфускатор и выйти |
| `--debug` | выкл | Сохранить промежуточные файлы в папку вывода |

## ⏱ Сколько это занимает

| Размер скрипта | Функций | Время (полная девиртуализация) |
|---|---|---|
| Маленький | 1–20 | 1–5 секунд |
| Средний (хабы) | 50–200 | 15–35 секунд |
| Большой | 500–750+ | 1–2 минуты |
| Любой, режим `--no-devirt` | любой | 1–3 секунды |

2. В архиве лежат только Windows-бинарники, поэтому Luau-рантайм собран из исходников (v0.660) и положен в `bin/luau` и `bin/luau-ast`.
3. Тест: `node deob.js sample/5ae248d6527b5c01.lua -o output/5ae248d6527b5c01.lua`
   - 170 КБ обфусцированного кода Luraph v15 → **за ~3 секунды** получен исходник из одной строки: `print("hello")` ✅

## ❓ Частые вопросы

**Выводится ошибка «luau not found».** Положите `luau`/`luau-ast` (Linux) или `luau.exe`/`luau-ast.exe` (Windows) в папку `bin/`.

**Python не найден.** Установите Python 3.10+ или задайте `PYTHON_BIN` (например, `set PYTHON_BIN=py` на Windows).

**Скрипт деобфусцировался частично.** Очень большие/хитро защищённые скрипты могут содержать места с маркером `error("devirt: unexplored successor ...")` — вместо неверного кода инструмент честно помечает непройденный участок. Попробуйте увеличить `--devirt-rounds` и `--max-runs`.

**Хочу только понять, что делает скрипт, без полного кода.** Используйте `--no-devirt` — за пару секунд получите полный трассировочный лог действий.
